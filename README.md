Репозиторий с выполненными практическими заданиями по курсу веб-разработки (HTML, CSS, JavaScript).

🔗 **Главная страница проекта:** [pape326.github.io](https://pape326.github.io/)

* **HTML5** — семантическая разметка страниц.

* **JavaScript** — интерактивность, работа с DOM и обработка событий.
